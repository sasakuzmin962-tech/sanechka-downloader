# САНЕЧКА HUB 3.0

Полноценный Windows-клиент на .NET 8 WinForms.

## Разделы

- Главная;
- Загрузки;
- История;
- Избранное;
- Профиль;
- Настройки;
- Уведомления;
- Админ-панель;
- Журнал администратора.

## Администрирование

Создатель может видеть пользователей, их роли и статусы, а также блокировать и разблокировать обычные аккаунты. Создатель не отображается в таблице с личным email/логином и не может быть заблокирован.

## База

SQLite-файл находится в:

`%LOCALAPPDATA%\SanechkaHub\sanechka-hub.db`

## Администратор

Логин: `sanechka_admin`

Пароль: `S4nechka!Hub#2026`

Эти данные не показываются в интерфейсе.

## Важное ограничение

Текущая 3.0 — локальный клиент. SQLite находится на компьютере пользователя. Поэтому `онлайн` и список пользователей не являются глобальными между разными компьютерами.

Чтобы сделать настоящий общий онлайн, регистрацию на одном сервере и видимость создателя для всех пользователей, нужен опубликованный сервер/API и общая серверная база. Клиентскую архитектуру можно расширить до этого без переделки интерфейса целиком.
